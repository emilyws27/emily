# Emily — Portfolio Website

A creative, data-themed portfolio website for a software engineer specializing in data engineering and data science.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (build tool)
- Custom CSS with CSS variables (dark theme)

## Features

- 🌐 **Hero** — animated particle network, typewriter effect cycling through roles
- 👤 **About** — bio, stats, and tech pills
- ⚡ **Skills** — animated skill bars across 4 categories (Data Engineering, Databases, Cloud, ML/Programming)
- 🚀 **Projects** — 6 project cards with tech tags, GitHub & demo links
- 🏢 **Experience** — timeline of work history
- ✉️ **Contact** — contact form + social links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the site.

## Build

```bash
npm run build
```
